# Бэкенд онлайн-записи и расписания «Vishenka» (Яндекс Документы + VK)

Этот бэкенд обеспечивает двустороннюю интеграцию сайта **Vishenka** с таблицами **Яндекс Документов (Яндекс.Диск)** и отправку уведомлений администратору в **ВКонтакте**.

---

## 🚀 Как это работает

1. **Расписание на сайте**:
   - Сайт запрашивает актуальное расписание из файла Excel на Яндекс.Диске (`/Vishenka/vishenka_studio.xlsx`).
   - Расписание кэшируется на сервере (60 секунд) для сверхбыстрой загрузки страниц (<50 мс).
   - Администратор может открыть таблицу в Яндекс Документах с телефона или ПК и изменить время, тренера или лимит мест — сайт автоматически обновится.

2. **Заявки и бронирование**:
   - Клиент выбирает тренировку и заполняет форму на сайте.
   - Бэкенд автоматически дописывает новую строчку во вкладку **«Записи»** на Яндекс.Диске и уменьшает количество свободных мест во вкладке **«Расписание»**.
   - Администратор мгновенно получает уведомление в диалог **ВКонтакте** со всеми данными клиента.

3. **Автономный Fallback**:
   - Даже если Яндекс.Диск временно недоступен или токен ещё не введен, сайт сохраняет все заявки в локальный файл `api/data/vishenka_studio.xlsx`. Ни одна заявка не потеряется!

## 🛠️ Настройка интеграции с Яндекс.Диском (За 2 минуты)

Чтобы таблица синхронизировалась с вашим личным или корпоративным Яндекс.Диском:

1. Перейдите на [oauth.yandex.ru](https://oauth.yandex.ru/) под вашим Яндекс-аккаунтом.
2. Нажмите **«Создать приложение»**:
   - Название: `Vishenka Site`
   - Платформы: выберите **«Веб-сервисы»** -> в поле Callback URL введите `https://oauth.yandex.ru/verification_code`
   - Доступы (Скоупы): найдите **Яндекс.Диск REST API** и отметьте галочками:
     - `Доступ к папке приложения на Диске (cloud_api:disk.app_folder)` или
     - `Доступ ко всему Диску (cloud_api:disk.write, cloud_api:disk.read)`
3. Нажмите **Сохранить**, затем перейдите по ссылке для получения токена:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_ID_ПРИЛОЖЕНИЯ`
4. Скопируйте полученный токен и вставьте его в файл `api/config.php` в поле `oauth_token`:
   ```php
   'yandex' => [
       'oauth_token' => 'y0_AgAAAAB...',
       'file_path'   => '/Vishenka/vishenka_studio.xlsx',
   ],
   ```
5. Откройте в браузере `https://ваш-сайт.ru/api/index.php?action=setup` — бэкенд автоматически создаст красивую готовую таблицу с расписанием прямо на вашем Яндекс.Диске!

## 📱 Настройка уведомлений ВКонтакте

В файле `api/config.php` настроен блок `vk`:
```php
'vk' => [
    'enabled'      => true,
    'access_token' => 'vk1.a....', // Токен сообщества или личной страницы
    'peer_id'      => 74933608,   // ID администратора для получения сообщений
],
```

Для проверки отправки тестового уведомления в VK перейдите:
`https://ваш-сайт.ru/api/index.php?action=test&test_vk=1`

## 📂 Структура таблицы в Яндекс Документах

Книга `vishenka_studio.xlsx` содержит две вкладки:

### 1. «Расписание»
- **Филиал** (Ла-Рошель / Зайцева)
- **День недели** (Понедельник ... Воскресенье)
- **Время** (например: 09:30, 18:30)
- **Направление** (Пилатес, Здоровая спина, TRX и т.д.)
- **Преподаватель**
- **Всего мест** (по умолчанию 8)
- **Занято мест** (счётчик)
- **Осталось мест** (формула `=G2-H2`)

### 2. «Записи»
- Дата и время записи
- Имя клиента
- Номер телефона
- Филиал
- Направление
- Дата и время тренировки
- Тренер
- Запрос / цель клиента
- Источник перехода
